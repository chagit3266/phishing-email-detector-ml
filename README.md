# Phishing Email Detector (Machine Learning)

This project implements a machine learning model for detecting phishing emails.
The goal is to classify emails as **phishing** or **legitimate** based on extracted features from email content.

## Project Description

The project uses a labeled dataset of emails and applies standard machine learning techniques:
- Data preprocessing
- Feature extraction
- Model training
- Model evaluation

All the steps are implemented in a Jupyter Notebook.

## Files in the Repository

- `index.ipynb` – Main notebook containing the full ML pipeline
- `email_phishing_data.csv` – Dataset used for training and testing the model

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Goal
To demonstrate a complete machine learning workflow for phishing email detection, from raw data to model evaluation.
